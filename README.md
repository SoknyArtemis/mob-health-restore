# 生物血量调整 Mob Health Tuner

一个《饥荒：联机版》（Don't Starve Together）服务端 mod：把生物血量统一乘以
系数（默认 **50%**），还原联机版官方为多人难度调高的血量。

## 背景

联机版官方为提高多人难度，调高了许多非友好生物的血量——源码
`tuning.lua` 里标注了 `-- harder for multiplayer` 的共 33 项，乘数不全是 ×2
（发条三件套 ×3、远古守护者 ×4、树精/坎普斯等 ×1.5）；此外联机新增/重做的
生物（蜂后、克劳斯、蘑菇蛀虫、帝王蟹、蚁狮、龙蝇、织影者、天体英雄、海洋与
裂隙生物等）也带有明显偏高的血量。本 mod 按「一律 50%」策略处理：除纯友好
生物外，不管是否被官方调过、不管是原版还是联机新增，血量一律乘以系数。

## 使用

本 mod 的实体目录就是游戏的
`~/.steam/steam/steamapps/common/Don't Starve Together/mods/mob-health-tuner/`
（游戏不识别 mods 目录里的软链接，所以实体必须放在那里）；
`~/Projects/mob-health-restore` 是指向它的软链接，两个路径编辑的是同一份文件。

创建/编辑世界时在服务器 mod 里启用本 mod，按需调整配置。

**纯服务端生效**（`all_clients_require_mod = false`），进服的玩家不需要订阅。

## 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| 影响其他 mod 的生物 | 否 | 默认只影响原版生物 |
| 日志输出 | 关 | 打开后在服务器日志打印每次调整（`[MHR]` 前缀） |

血量系数固定为 50%，不在设置界面调整；个别生物需要不同系数或完全排除时，
编辑 `scripts/mhr_config.lua` 里的 `OVERRIDE` / `EXCLUDE` 表。

mod 名字与介绍按游戏语言显示（中文：生物血量调整 (Mob Health Tuner)，
其他语言：Mob Health Tuner），基于 modinfo 沙箱官方提供的
`ChooseTranslationTable`（zh/zht，不面向国服）。想生成受影响生物名单
数据时，可用 `tools/gen_affected_list.sh`（全量 spawn 枚举）。

## 默认不受影响的单位

- **玩家、宠物（Critter）、墙体、建筑与巢穴**（蜘蛛巢、蜂窝、狗窝、水獭窝
  等带 structure tag 或在排除表中的）
- **玩家载具**：船、龙舟赛用船、防撞栏（boat / boatbumper tag）
- **纯友好生物与玩家召唤物**（排除表）：切斯特、哈奇、格罗姆、阿比盖尔
  （随温蒂成长的专属血量系统）、沃比、伯尼、麦斯威尔影子仆从、小鸟、
  薇诺娜投石机、珍珠、瓦格斯塔夫、大虎、波莉·罗杰、岩浆虫宠物、
  沃姆伍德技能植物宠物（胡萝卜/果蜥龙/光翼虫）、鱼人王、靶子
- **血量被游戏机制挪用的对象**（排除表）：牌堆（血量当计数器）、
  被附身的尸体（与真实玩家关联）、龙舟赛障碍物
- 注意：按「一律 50%」策略，**官方没调过血量的中立生物（猪人 250→125、
  兔人 200→100、蜘蛛 100→50、猎犬 150→75 等）也会被减半**。这是设计决定，
  不想要的话在 `EXCLUDE` 里逐个加回。

## 技术原理

- 血量在 prefab 构造时经 `health:SetMaxHealth()` 设置；本 mod 用
  `AddPrefabPostInitAny`（任何实体生成后必经）读取当前 `maxhealth` 乘系数。
- 同时把该实体 `health` 组件的 `SetMaxHealth` **包装一层**，因此生成之后的
  任何重设（帝王蟹镶嵌宝石重算、Boss 缩放变身等）也自动保持系数。
- 原版/非原版判定：`mhr_vanilla.lua` 静态名单（从游戏脚本生成）∪ 运行时
  反查 `ModManager.mods[i].Prefabs`（DST 的 mod prefab 都记录在此）。
- 客户端没有 health 组件，钩子天然只在服务端生效。
- 对已有存档：载入时当前血量若超过新上限会被截断（满血怪直接变半血），
  新开档无感。

## 实测

在本地专用服务器（离线集群）上批量 spawn 验证（build 756039）：

- 被官方 ×2 的：独眼鹿 4000→2000、熊灌 6000→3000、鹿鸭 6000→3000、
  野牛 1000→500、无尾象 1000→500、高鸟 800→400、蜘蛛女王 2500→1250、
  石虾（体型 0.75）2250→1125、海象 300→150
- 被官方 ×1.5/×3/×4 的（按一律 50% 处理）：树精 3000→1500、坎普斯 300→150、
  发条三件套 900→450、warg 1800→900、远古守护者 10000→5000
- 联机新增/重做：龙蝇 27500→13750、蜂后 22500→11250、克劳斯 10000→5000、
  帝王蟹 12000→6000、蘑菇蛀虫 52500→26250、蚁狮（配置值 6000→3000）、
  Malbatross 5000→2500、Rock Jaw 1000→500、海洋植物 500→250
- 排除项保持原样：切斯特 450、格罗姆 100、阿比盖尔、蜘蛛巢 250、木墙 200、
  投石机 400、水獭窝 350 等

## 开发与维护

```bash
# 游戏大版本更新后，重新生成原版 prefab 名单
./tools/gen_vanilla_list.sh

# 本地专用服务器回归测试（自动写入临时 harness mod 并批量 spawn 打印血量）
./tools/test_on_server.sh
```

测试脚本依赖本机装有 DST；openSUSE 下需要 `libcurl-gnutls.so.4` 的替代
链接（脚本会自动处理）。

## 已知边界

- 与其他**绝对值**改血 mod 叠加时，后加载的一方生效；本 mod 是乘法，若对方
  用 `AddPrefabPostInit` 设绝对值（其执行先于本 mod 的 PostInitAny），
  结果为「对方数值 × 系数」，通常可接受。
- 阿比盖尔的血量由专属系统随游戏天数成长，故排除；如需调整请用温蒂相关 mod。
